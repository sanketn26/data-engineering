## When to Use This Section

Use the selection framework when:
- You are designing a new system and need to choose between options
- A stakeholder asks "why not just use X for everything?"
- You want to validate an architectural decision systematically

Use the glossary when:
- You encounter an unfamiliar term in the academy material
- You want to check a precise definition before using it in a design doc
- You are explaining a concept to someone else

---

## What This Is Not

This reference section does not replace understanding. If you are looking up "what is a watermark" repeatedly, that is a signal to go back to the [Flink time semantics module](../flink/time.md) and build the intuition.

The goal of this academy is that these terms become part of your working vocabulary — not something you need to look up.
